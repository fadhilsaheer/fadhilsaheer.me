# Classic pixel trainer

This revision returns to the first trainer's compact chibi design: large expressive eyes, a large head, narrow shoulders, and small, clear pixel clusters. The neutral default has a closed mouth with no grin or visible teeth.

The first supplied portrait is used only for subtle likeness details: rounded black aviator glasses, wavy black hair, eyebrows, moustache, and light chin/jaw stubble. Preserve the original cartoon proportions rather than replacing them with a realistic portrait.

Source sheets are retained here for rebuilding. The page-mascot pipeline uses nearest-neighbour resizing, crisp 72px logical frames enlarged into the atlas, lossless WebP, and no bottom blur. Both directions and reactions must pass the alignment checks. Photos are not included in the repository.
